# Puzzle Reveal — เกมทายภาพจิ๊กซอ

เปิดจิ๊กซอทีละชิ้นเพื่อทายภาพ ใส่หลายรูปได้ เล่นต่อเนื่องรูปที่ 1, 2, 3 …

## ใช้งาน
```bash
npm install          # ครั้งแรกครั้งเดียว
npm run dev          # โหมดพัฒนา  (http://localhost:5173)
npm run build && npm run preview   # โหมดใช้งานจริง (แนะนำสำหรับวันงาน)
```
- รูปและความคืบหน้าเก็บในเบราว์เซอร์ (IndexedDB/localStorage) ต้องใช้ **เบราว์เซอร์และเครื่องเดิม** ตอนเล่น
- คีย์ลัดในหน้าเล่น: `Space` เฉลย/ภาพถัดไป · `← →` เปลี่ยนภาพ · `F` เต็มจอ · `N` ซ่อน/แสดงเลขชิ้น
